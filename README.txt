DANISH KHAN — PREMIUM BIRTHDAY WEBSITE
========================================
Birthday: 20 August
Relationship: Brother
Photos: images/1.jpg through images/6.jpg

GITHUB PAGES:
1. Upload/unzip the project.
2. Keep index.html, style.css, script.js and the images folder together.
3. In GitHub: Settings -> Pages -> Deploy from branch -> main -> / (root).
4. Save and open the generated Pages link.

IMPORTANT:
- The website has a browser-safe synthesized birthday melody. Browsers usually block autoplay,
  so tap the Music button once to start it.
- To add more photos later, put them in images/ and add their filenames to the slideshow code.
